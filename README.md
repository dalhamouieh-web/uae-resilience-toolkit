# UAE Resilience Toolkit

Practical, reusable templates for **operational resilience, ICT risk and third-party risk** in UAE financial institutions, onshore (CBUAE) and in the free zones (DFSA, FSRA). Built alongside *The Resilience Bridge*, a newsletter that brings lessons from Europe's DORA to the Gulf.

Each folder matches one edition of the newsletter. Each one contains a short guide, an Excel workbook and the same data as CSV files, filled with examples for **Bank Horizon**, a fictional bank. Replace the examples with your own.

> All data is fictional and illustrative. These are templates, not legal or regulatory advice. Always check the official texts.

## How to use it

1. Open the folder for the topic you need and read its README (five minutes).
2. Open the Excel workbook. Light yellow cells are the ones to edit.
3. Use the CSV files if you want to load the data into another tool.
