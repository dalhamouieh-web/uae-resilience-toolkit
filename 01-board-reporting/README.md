# 01. Board reporting: the one-page Board report

**Newsletter:** Edition 1, *The One-Page Board Report*.

A sample layout of the key information a Board-level resilience dashboard should contain: overall position and decisions, six resilience outcomes, the external threat view, key risk indicators, Critical Operations against tolerance, incidents, third parties, testing and remediation.

- **Live sample:** https://dalhamouieh-web.github.io/resilience-board-dashboard/
- **Code and sample data:** https://github.com/dalhamouieh-web/resilience-board-dashboard

It is a layout, not a finished product. Folder `02-reporting-chain` explains what it takes to produce the numbers behind it.
